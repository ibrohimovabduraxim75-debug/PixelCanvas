Keyboard shortcuts

F7 / F6 / F8 New frame / duplicate frame / delete current frame
Left / Right Previous / next frame (if it exists)
Alt + Left / Right Move the current frame earlier / later
Home / End First / last frame
Space Play / pause
F11 Fullscreen playback (Esc to exit)
M / G Mute sound / show a grid
Audio button Add a sound to the current frame, add music, edit volume, speed and trimming. You can also drop an audio file on a frame.
Speed Playback speed (also in fullscreen and on the Online page)
S Select (rectangle / lasso / magic wand panel at top-left)
Q / W Lasso / magic wand
P / B / A Pencil / brush / smudge
F / E / I Fill / eraser / eyedropper
L / R / O / U Line / rectangle / ellipse / shapes (Shift = constrain)
T / H / Z Text / hand (pan) / zoom (Alt+click = zoom out)
[ / ] Decrease / increase tool size
Mouse wheel Zoom (middle button drags the canvas)
Selection Drag inside = move, square handles = resize (Shift on corners = keep ratio), round handle = rotate (Shift = 15 degree steps)
Shift + Arrows Nudge the selection by 1 px
Ctrl+Z / Ctrl+Y Undo / redo
Ctrl+C / X / V / A Copy / cut / paste / select all
Delete Delete selection (or clear the frame if nothing is selected)
Enter / Esc Apply / cancel selection
Ctrl+S Save to this site
Ctrl+0 Fit canvas to window
